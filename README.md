# 한국 주식 이동평균선 전환 검색기

GitHub Pages용 정적 웹사이트입니다. GitHub Actions가 네이버 금융 데이터를 주기적으로 수집해 `data/stock-data.json`을 만들고, 브라우저는 이 파일을 읽어서 이동평균선 전환 조건을 계산합니다.

GitHub Pages 배포 후에는 저장소의 Actions 탭에서 `Update stock screener` 워크플로우가 실행되며, 그 과정에서 전체 종목 데이터가 생성됩니다.

로컬 서버로 테스트하려면 `start_stock_site.bat`를 실행한 뒤 `http://127.0.0.1:8787`로 접속합니다.

## A-G 30분봉 신호 감시

`피라미드형3MA반등`의 반등 직전 봉은 반드시 MA3 < MA60이어야 합니다. 이미 MA60 위에서 움직이던 MA3의 소폭 반등은 포착에서 제외합니다. 아래에서 상승 전환과 MA60 상향 돌파가 같은 봉에 발생하는 경우의 확인 알림은 유지합니다.

MA60 부근 반등형의 사전검토 알림: MA3가 MA60 아래로 실제 내려간 뒤, 아래에서 간격 2.5% 이내인 완성 30분봉이 3개 연속 나오면 `피라미드형 상승가능성 검토요청`을 보냅니다. 상승 전환 전에도 장후 포함 발송하며, 동일 이탈 구간에서는 한 번만 보냅니다. 간격이 2.5%를 넘으면 연속 봉 수를 다시 세고 MA60 이상 회복 후 다시 이탈해야 새 구간입니다. 같은 봉에서 기존 반등·돌파 알림이 발생하면 그 알림을 우선하며 중복 발송하지 않습니다. MA20 급등락이나 일봉 조건을 다시 추가한 것이 아니며 다음 날 상승 보장은 아닙니다.

이미지공부의 아이컴포넌트 `상승하락상승` 이미지는 완성된 30분봉의 MA3·MA60 근접 반등 조건에만 연결합니다. 직전 봉 MA3 < MA60이고 MA3가 하락·수평 후 상승 전환하며 반등 확인봉의 간격이 MA60 대비 ±2.5% 이내이면 1차, 이후 실제 MA60 상향 돌파 시 확인 알림입니다. 직전 봉의 간격에는 제한을 걸지 않습니다. 대성산업 10월 15일 19:00 완성봉의 간격 2.41%를 포함하며 직전 봉의 2.66% 이격은 제외 사유가 아닙니다. 재하락 또는 2.5% 범위 이탈 시 확인 대기를 취소합니다. 상승 전환과 돌파가 같은 봉이면 확인 1건으로 합칩니다. 일봉 MA5 조건은 사용하지 않습니다. 이전 MA20 피라미드 조건은 중단하며, 대성산업 `하루하락후수평조정상승` 이미지는 삭제하지 않습니다. 2.5%는 등록 예시에 맞춘 잠정 기준이며 수익률 검증 결과가 아닙니다.

`monitor.html`은 최근 10거래일 안에 A-G가 발생한 종목을 관리하고, 네이버 분봉을 30분봉으로 묶어 MA20이 MA40 아래에서 반등한 뒤 5회 연속 상승했는지 표시합니다.

`history.html`은 10거래일 관리가 끝난 A-G 후보를 메인 감시화면과 분리해 보관합니다. 종료 후보별 A-G 발생일, 매수포착 일시·가격·돌파선, 목표달성 일자·가격·거래일 수와 최고·최종 수익률을 검색할 수 있습니다. 목표달성가는 A-G 발생일 종가 대비 +5% 기준입니다.

- 핵심 A-G 후보: A 거래량 증가율 200% 이상, E 종가 상승률 1% 이상
- 확대 A-G 후보: A 거래량 증가율 150% 이상, E 종가 상승률 0.5% 이상. B·C·D·F·G는 핵심 후보와 동일
- 확대 A-K 후보(잠정 추가): 1봉 전 거래량의 20일 평균 대비 변동률 +200% 이상, 1봉 전 MA40 3회 연속 상승, 오늘 종가 -2% 이하, MA10 > MA20이고 두 선 간격 확대, 오늘 MA5 <= MA120, 6봉 전 MA10 <= MA60을 모두 만족하고, 4→3·3→2·2→1봉 전 종가 상승률 중 하나 이상이 +9% 이상이어야 합니다. +9% 기준은 2026-10-16 선정분부터 적용하며 이전 선정분은 +10%를 유지합니다. 검색식은 `A and B and C and D and G and H and (I or J or K)`입니다. 기존 A-G 관리 중인 종목의 등록일·등록가는 유지하며 중복 등록하지 않습니다. `AK_SEARCH_ENABLED`로 신규 A-K 검색만 중단할 수 있고, 이미 등록된 A-K는 관리기간까지 유지합니다.
- 두 등급 모두 동일한 10거래일 관리기간과 30분봉 매수 판정·제외 기준을 적용합니다.

- 일봉 후보 갱신: `.github/workflows/update-pages.yml`
- 장중 10분 간격 감시: `.github/workflows/monitor-signals.yml`
- 휴대폰 푸시: 저장소 Secret `NTFY_TOPIC`이 설정된 경우에만 ntfy로 전송
- 핵심종목 아침 MA3 알림: 전일 핵심종목 메뉴에 해당한 종목만 대상으로, 전일 최종 MA3 < 09:30 확정 MA3 < 10:00 확정 MA3일 때 종목별 하루 한 번 전송합니다. 실제 30분봉 MA3 값을 사용하며 이후 봉의 상승으로 조건을 다시 판단하지 않습니다. 데이터 지연·전송 실패 재시도도 이 고정된 두 봉만 사용하고 오전 11시부터는 발송하지 않습니다.
- 신호는 자동주문이 아니라 다음 30분봉부터 HTS 현재가를 확인하기 위한 매수 검토 알림입니다.
- MA20 5회 연속 상승 후, MA20이 MA40 아래까지만 조정되었으면 MA3의 MA40 돌파를, MA60 아래까지 조정되었으면 MA3의 MA60 돌파를 매수 포착으로 사용합니다.
- A-G 통과 후 매수시점은 30분봉 MA20·MA40·MA60 흐름으로 판정합니다. 일봉 MA10은 차트 참고선이며 신호를 보류하는 조건으로 사용하지 않습니다.
- 후보 등록 시 확보한 과거 30분봉을 저장하고 이후 봉을 누적해 최대 220봉으로 MA3·20·40·60을 계산합니다. 그래프는 최근 5거래일을 표시합니다.
- 현황판의 후보별 `보유등록` 버튼은 종목코드, 종목명, 대량거래 전일 종가 기준 손절가를 중앙 입력창에 자동으로 채웁니다.
- 최초 한 번 fine-grained GitHub 연결키(Actions 쓰기 권한)를 휴대폰 브라우저에 저장하면 중앙 입력창에서 등록·수정·매도완료를 처리할 수 있습니다.
- 매수·매도 시 수량과 체결가를 입력하며 매수금액·평가금액·실현수익률·총손익을 매도이력에 보관합니다(세금·수수료 전).
- 보유종목은 목표수익률 5%를 사용합니다. 기술적 손절가가 매수가 대비 -5%보다 낮으면 -5%로 제한하고, -5% 이내면 기술적 손절가를 그대로 사용합니다.
- 손절 알림은 장중 일시 이탈로 확정하지 않고 15:00 이후 확인가격이 손절가 이하일 때 보냅니다. `종가 < MA20`이면서 MA20 3봉 연속 하락하는 추세약화도 별도로 감시합니다.
- ntfy 알림은 최대 우선순위 5로 전송하며, 알림을 누르면 해당 종목이 선택된 감시화면과 그래프로 이동합니다.
- 일봉 그래프는 장중 감시 때도 갱신해 오늘 현재가를 포함합니다.
- 후보가 10거래일 관리에서 빠질 때 A-G 조건값, 매수포착 정보, 최고·최종 수익률과 +5% 달성 여부를 최대 1,000건 보존합니다. 달성률은 A-G 발생일 종가 대비 관리기간 중 일봉 고가를 기준으로 계산합니다.
- 매수포착 기록과 +5% 달성이 모두 확인된 후보는 달성 당일에는 메인에 유지하고, 두 조건이 모두 성립한 날의 다음 거래일에 검증 이력으로 자동 이동합니다.
